# Security

**UNCLASSIFIED.** This repository is a public protocol and a fictional sample. Do not open issues, pull requests, or packs that contain CUI, classified data, API keys, credentials, or model weights.

A pack is an evidence record. URI pointers and hashes only. `ao-pack verify` looks for common secret patterns and weight filenames; that is a helper, not a guarantee.

If you find a defect in hashing, zip verify, or the schema that would let a pack lie about its contents, open an unclassified GitHub issue (or use private vulnerability reporting if it is enabled on this repo).
